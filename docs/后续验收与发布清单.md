## 当前已经做完

- 建立独立的应用、数据库、端口、数据卷和启停脚本。随源码发布 Apache-2.0 许可证和适用的开源来源声明。
- 建成商品咨询、规格比对、促销政策和售后服务四个入口。当前快照包含 44 条手机记录、71 款充电配件、4 条政策和 2 类故障。42 款手机有参数，其余两个定制或特别版保留商城公开销售规格。授权网点快照核对了 342 个城市选项，在 312 个城市找到 1,620 条网点记录。[本次分页与收录记录](../resources/store-catalog/listing-scan.json)
- 独立源码副本中，后端套件 806 项测试，780 项通过、26 项按配置跳过。另有 1 项技能工具生命周期定向测试通过。前端 43 项测试、TypeScript 检查与构建通过。18 项真实 MCP 与 PostgreSQL 检查通过，包含同一号源并发争抢、同请求幂等和账号隔离。
- 两个后端实例、工作台、pgvector、Elasticsearch、LightRAG 和 Neo4j 已运行。扩充后 121 份知识摘要的向量、关键词和图谱索引均已核对。再次导入核对了商品内容、知识文档 ID 和分块数，均保持一致。
- 用真实模型跑通机型比对和配件追问，售后完成到浏览器确认并生成本地预约 `DS-9`。发现并修复了虚拟列表导致确认卡刷新空白的问题，已在浏览器复验恢复。
- 登录页与工作台采用无图布局。桌面和 390 像素窄屏均实测四个快捷入口、预填聚焦和输入框，窄屏会话侧栏可用菜单和 Escape 操作。

## 可复用入口

在项目根目录运行以下命令。启动脚本会按需提示输入本机凭据。

```powershell
.\local\Stop-StoreAgent.ps1
.\local\Start-StoreAgent.ps1 -RetrievalMode Hybrid
.\local\Import-StoreAgentDemo.ps1
.\local\Verify-StoreAgentMcp.ps1
```

用 `.\local\Start-StoreAgent.ps1 -RetrievalMode Hybrid -SecondNode` 启动第二个后端实例。原始网页快照、模型凭据、交互日志及测试账号文件保存在本机忽略目录。当前验收证据见 [验收记录](acceptance.md)。
